## Scope and implementation

An architectural inspection hotspot: full façade → choose Balance, Monumental Entrance, or Ventilation & Protection → inspect an architectural detail → return to the same context. Modes are parallel and never gated. No scores, progression, completion tracking, or historical material outside the approved architectural scope.

Production uses the existing ConferenceRoomInteraction scene/class, its heritage theme, signals, Sources overlay and narration player. PPC-EXT-02 rearranges that shell into header → photo canvas → main modes → short interpretation. No shared or PPC-EXT-01 files were edited. The existing ConferenceRoomContent and ConferenceRoomConceptEntry Resources hold all approved historical text and documentary mappings. Entry metadata identifies each record, its button label, note/caption and optional image; no additional Resource class was necessary.

## State and interaction

One authoritative select_architecture_view method controls overview/balance/entrance/climate. Supporting state is balance_reveal, entrance_feature and climate_layer. The single detail viewer uses detail_view_open, detail_id and detail_origin_view. It blocks background actions through its closing fade, cancels interrupted modal fades and restores focus to the originating detail button.

Balance:
- Continuous reveal in [0,1], driven by mouse/touch drag across the canvas/52px drag strip.
- Left/Right moves by 0.1 when the reveal canvas is focused.
- DRAG TO REVEAL THE BALANCE; a central axis and paired broad regions grow from the center.
- The rail uses the upper sky area and does not shrink the photo or obscure the façade/steps at the tested sizes.
- The original photograph is never mirrored or reconstructed. No mathematically perfect symmetry claim or completion outcome.

Entrance:
- Moderate 1.32× contextual zoom, centered toward the entrance, over 300 ms.
- Four 48px-minimum controls: BROAD STEPS, PORTICO, IONIC COLUMNS, MAIN DOORS.
- Starts with no feature selected; subsequent visits preserve the local selection.
- Restrained corner brackets, distinct portico and pediment interpretation.
- MAIN ENTRANCE and PEDIMENT & RELIEF are secondary architectural-detail choices.

Climate:
- AIRFLOW, SHADE and RAIN; default airflow.
- Window regions and restrained arrows, shaded colonnade regions, or covered/cornice regions and a few downward strokes.
- “INTERPRETIVE VISUAL GUIDE” explicitly identifies the diagram as interpretation, not an engineering simulation.
- Airflow offers WIDE INTERIOR CORRIDOR; shade offers BACK ENTRANCE PASSAGEWAY; rain has no invented detail.

All annotation points map normalized source-image coordinates through the actual aspect-preserving displayed photo rectangle, including entrance zoom. They are not viewport-relative. The main photo stays directly linked to PPC-EXT-01's government-today JPEG.

Main interpretation fade: 200 ms. Entrance crop: 300 ms. Feature highlight: 180 ms. Climate highlight: 200 ms. Detail opening/closing: 200 ms. Reveal follows input directly. Replaced Tweens are cancelled.

## Input, focus and responsive behavior

Touch and mouse use the same generous mode/feature/layer/detail buttons. Godot BaseButton handles touch; emitting an additional touch activation would duplicate the engine's emulated click, so the implementation avoids that. Reveal supports native touch drag and mouse drag explicitly. No hover-only information.

Keyboard Enter/Space activates buttons. Focus styling uses the shared cream outline, distinct from gold selected state. Tab/Shift+Tab wrap within the current context:
- Overview: three modes → SOURCES → LISTEN → CLOSE.
- Balance: reveal canvas → detail → FULL FAÇADE → other modes → header.
- Entrance: four features → two details → FULL FAÇADE → other modes → header.
- Climate: three layers → relevant detail → FULL FAÇADE → other modes → header.
- An overflowing local interpretation scroll area follows the header controls when needed.
- Detail opens focused on CLOSE DETAIL; its scroll area joins the focus trap only when needed. Closing returns to the exact opening detail button.
- Sources traps focus in its close/scroll controls. Closing returns to SOURCES.

Focus order is refreshed after text reflow changes scroll extent.

Escape priority: close Sources → close Architectural Detail → return from an architectural mode to Full Façade → close hotspot from overview. Input is marked handled before any navigation/close signal.

Tested landscape sizes: 1280×720, 960×540, 854×480. Compact layouts reduce decorative spacing and use readable 17px interpretation text, 14px button labels and 48px minimum button height. Photographs remain aspect-preserving, annotations track them, and text scrolls locally rather than pushing the full panel off-screen. Main canvas remains above mode controls; detail photographs remain dominant.

## Reset

Hotspot close/host hide resets overview, reveal=0, entrance=none, climate=airflow, detail closed/IDs none, Sources closed, audio stopped/playback reset, all local scroll positions, photo zoom, drawing state and active Tweens. Close returns to the launcher. Reopen always starts fresh. Within an open session, switching modes retains reveal, entrance selection and climate layer.
