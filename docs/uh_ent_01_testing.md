# UH-ENT-01 — The Story of Urduja House

This is an independently testable, optional historical-video interaction. It has
no exterior/lobby navigation, master-scene integration, analytics, or completion
requirements. The specification remains read-only. The researcher-approved final
transcript and verified credits are still pending; they must be resolved before
deployment. No transcript was inferred or generated from the video.

## Public API and signal contract

- `content: HistoricalVideoContent`: assign before opening.
- `open_interaction(return_focus: Control = null) -> bool`: opens without autoplay,
  remembers prior focus, resets video-local volume to normal, and focuses Watch.
  Missing video disables playback controls while keeping transcript/Skip/Close
  available. Missing content returns false.
- `is_interaction_open() -> bool`: current visibility state managed by the component.
- `watch()`: starts from the beginning if stopped; otherwise continues and restores
  video-local sound. Does not alter global audio preferences or buses.
- `play_without_sound()`: starts or continues the same player with volume 0.
- `replay()`: stop/play restarts Theora from the beginning, preserving the current
  local sound mode. It does not rely on seeking and never adds another player.
- `show_transcript()` / `hide_transcript()`: work without starting playback.
  Opening pauses active playback, moves focus to Close transcript, and resets
  scrolling. Closing resumes only if it was playing and returns focus to
  Read transcript. The supplied placeholder and a separate warning clearly
  identify the text as development-only, not validated historical content.
- `skip()`: stops/hides safely and emits `skip_requested`; no completion check.
- `close_interaction()`: stops/hides safely and emits `closed`.
- Signals: `opened`, `closed`, `skip_requested`, `playback_started`,
  `playback_finished` (all no arguments).

`playback_started` fires on a fresh start or Replay, not a sound-mode switch.
Natural completion updates the status/pressed sound controls and emits
`playback_finished`; it never navigates or records progress. Exactly one terminal
signal is emitted per dismissal: `skip_requested` for Skip, otherwise `closed`.
Cleanup happens before these signals so a host can safely remove the component.
Closing restores the remembered focus owner deferred if still usable. Hosts can
pass an explicit return control when opening programmatically.

Escape/Backspace use the existing go_back action. The component consumes the
window input first, closes the transcript first if visible, and otherwise closes
the whole interaction. Tab and standard Enter/Space activation use Godot Buttons;
no additional E binding or duplicate keyboard handler is introduced.

## Exact Godot F6 tests

1. Open `project.godot` in Godot 4.7 and finish asset/script scanning. Open
   `scenes/landmarks/urduja_house/supporting/uh_ent_01.tscn`, then press **F6**
   (Run Current Scene). Do not change the main scene. Use **1280 × 720**.
2. Confirm the development header and prompt are readable. No video/audio should
   start automatically. Click the prompt; check the title, all six controls,
   visible Watch focus, and proportionally sized 16:9 video area. Controls must
   remain on-screen. Resize the run window and check the reference stretch layout.
3. Before playing, select **Read transcript**. Confirm the exact supplied
   DEVELOPMENT TRANSCRIPT PLACEHOLDER and the separate development-only warning.
   Nothing must be presented as a final historical transcript. Scroll with the
   mouse wheel; Tab to the scroll area and use arrows/Page Up/Page Down. Confirm
   Close transcript is focused initially. Test its button, Escape, and Backspace:
   only the transcript closes, returning focus to Read transcript.
4. Before playing, choose **Skip for now**. Confirm the popup closes and the
   standalone development status says Skip requested and identifies future master
   scene integration. Focus returns to the prompt. No lobby scene is opened.
5. Reopen and select **Watch**. Confirm the supplied video starts, embedded audio
   is audible, playback is smooth, and picture proportions remain 16:9. Check the
   Watch pressed state and status. Headless checks cannot verify audible quality.
6. Select **Play without sound** while playing. The same video must continue with
   only its audio muted. Select Watch again: sound returns without restarting.
   Also close/reopen and start directly with Play without sound. Global AKAR mute
   preferences/audio buses must remain unchanged; inspect the Master bus if needed.
7. Select **Replay** both during playback and after letting the video finish.
   It must restart at the beginning, preserve the selected sound mode, and use
   the same VideoStreamPlayer. Completion must keep the interaction open and
   permit Replay, transcript reading, Skip, or Close. No completion requirement.
8. Open the transcript during playback. Picture/audio pause while reading.
   Close transcript: prior playback resumes in its existing sound mode. If the
   video was not playing before reading, closing must not start it.
9. Test **Close**, **Escape**, and **Backspace** during playback. Video and audio
   must stop; focus must return to the standalone prompt. With transcript open,
   the first back closes transcript and the second closes the interaction. Skip
   must also stop playback and work while the transcript is visible.
10. Test Tab/Shift+Tab through all visible controls, visible focus, Enter and Space
    activation. Popup focus must stay modal. Repeated opening/closing, sound-mode
    switching, Replay, and Skip must not produce duplicate UI, stuck focus, audio
    after closing, missing resources, or Debugger errors.
11. Stop with **F8**. **F5** must still run the unchanged application foundation.
    For browser QA, export a disposable project copy with this standalone scene
    as its main scene, serve over HTTP, and repeat playback/input checks. Do not
    modify the real project's main scene or export settings for this milestone.

  tracked file changed; `project.godot` was not reserialized.
